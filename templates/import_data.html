Import Instructions
Adding and updating equipment
  • New equipment: leave eq_id blank. equipment_class is required.
  • Editing in bulk: export from the Equipment List (use its filters to narrow it down), edit the file, and import it here. Rows whose eq_id already exists update that record.
  • Only the columns in your file change. Delete columns you are not editing and those fields are left alone. A blank cell clears that field.
  • Each row is saved on its own. Rows with problems are listed after the import and the rest still go in.
Formats
  • Dates: YYYY-MM-DD (Excel's M/D/YYYY also works)
  • TRUE/FALSE fields also accept YES/NO and 1/0. A blank means No, except Physics Coverage, where blank means Yes.
  • Audit frequencies: comma-separated, from Quarterly, Semiannual, Annual - ACR, Annual - TJC, Annual - ME
  • Unrecognized column names are reported and ignored, so check headers match the export exactly
Export-only columns (eq_mefacreg, eq_eeoldate, eq_capecst, eq_capcat) are calculated by the system and ignored on import, so it is fine to leave them in the file.

Personnel Matching:
  • A personnel ID matches that person exactly; otherwise the name is matched
  • A name that is not found creates a new person, which needs the email column filled in
  • People get the contact, supervisor, or physician role from the column they appear in
  • Existing people's emails are not changed by equipment imports

Need Help?

If you encounter issues with the import process:

  • Check that your CSV file has the correct column headers
  • Verify date formats are YYYY-MM-DD
  • Ensure numeric fields contain only numbers
  • Make sure boolean fields use TRUE/FALSE

For technical support, contact your system administrator.
